# Gerenciador de Tarefas via CLI
Este gerenciador de tarefas serve para ajudar o usuário a entender melhor o funcionamento de python, a leitura de arquivos, o uso de arrays e, principalmente, organizar as próprias idéias no projeto.

## Changelog
- 18/11/2026 - Base criada: o gerenciador realiza a leitura de um arquivo .json chamado "tarefas.json", cujo qual precisa possuir pelo menos um par de colchetes [] e insere os dados que o usuário quer inserir, além de salvar no arquivo e listar esses dados. <i>Ainda não é possível remover, marcar como concluído nem criar arquivos próprios, como outras listas</i>
